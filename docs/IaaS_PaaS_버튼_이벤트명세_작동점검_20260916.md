| 네트워크·라우터·FIP | 네트워크 생성(관리자)·서브넷 추가·라우터 생성·FIP 할당/해제/회수/재할당 | Neutron networks/subnets/routers/floatingips | 관리자 권한은 OPA 정책으로 검사 |
| 보안 그룹·키페어 | 그룹·규칙 CRUD, 키페어 생성·업로드·삭제 | Neutron security-groups/rules, Nova os-keypairs | 사용자 역할은 조회·선택만 |
| 볼륨 | 생성(빈/이미지/스냅샷)·확장·스냅샷·복원·연결·분리·삭제 | Cinder volumes/snapshots, Nova volume attachments | 재사용은 최종 형상 |
| 이미지·플레이버 | Glance 동기화·업로드, Flavor 목록 | Glance images, Nova flavors | 패키징 탭은 ETRI 이미지 빌더 연동 후 |
| 클러스터 | 신청·승인·생성·반려, Magnum 5단계 진행 | Magnum clustertemplates/clusters, Heat stack 상태 | 승인 흐름은 포털 DB(2단계)로 영속화 |
| 워크로드 | 생성 위저드·스케일·롤아웃·롤백·삭제, 스케줄링 힌트 | K8s apps/v1 Deployments·StatefulSets·DaemonSets, batch/v1 Jobs·CronJobs | sched.ai/·profile.ai/ 라벨·어노테이션 기록 |

| 스토리지 | PVC 생성·확장, PV·StorageClass 생성(관리자) | K8s PersistentVolumeClaims/PersistentVolumes/StorageClasses (Ceph CSI) | |

단계: ① 조회 API부터 연결(목록·상세, 1~2일) → ② 생성·변경·삭제 액션 연결(2~3일) → ③ 권한(Keycloak 로그인 + OPA) 적용 → ④ DB 연결(신청·승인·감사). 액션마다 성공·실패 알림과 목록 재조회를 공통 훅으로 처리한다.

- 이 문서의 실행 점검 스크립트(`qa-iaas-paas.mjs`)를 회귀 테스트로 재사용한다. 판정 기준을 ‘알림 표시’에서 ‘API 응답 후 목록 갱신’으로 바꾸면 실구현 검증에도 쓸 수 있다.
